## 开关与使用

设置仍需在面板保存；模块开关和功能开关分别生效。切换到此分支不会自动打开真实外部发送。

- **聊天**：收到文本文件读取、按 QQ 号排除、@ 他人唤醒词抑制、seedHistory、DSH 审批通知、跨群共享规则。
- **表情**：auto/ask/owner 收集策略；单个素材的仅手动发送。ask 由当前请求的候选 ID 选择，不接受其他聊天的 ID。
- **语音**：RVC 开关、音色、音高、失败策略及超时。人格 → 语音的每项留空即继承全局，必须发布才生效；不自动安装运行时。`original` 失败回原声，`error` 返回失败。
- **生图**：默认构图、作品视觉反馈、作品库。作品库复用只建立现有作业的参考，不扫描本机目录。
- **主动搭话**：目标列表为空时保留主人私聊默认；填入 `group:群号` 或 `private:QQ号` 后还需相应白名单。选择目的模式后，手动按钮和 `/speak 目标` 同样使用目的决策。
- **B 站**：看画面开关、抽样数与 FFmpeg 路径；单独填写 B 站主人昵称/MID 才能可靠解析 `@主人`；弹幕另行开启并设置额度。不要把 QQ 昵称当 B 站账号。

跨群共享规则例子（换成自己的机器人账号、主人号、群号与人格 ID）：

```json
[
  {
    "enabled": true,
    "account": "20000002",
    "persona": "fish",
    "fromChatId": "private:10000001",
    "targetChatId": "group:62001"
  }
]
```

这只允许主人从指定私聊读取指定群。机器人和主人均应在群中，群须在白名单，两个聊天使用同一人格。`qq_summarize_history` 返回有证据的有限素材，当前模型据此总结；不是全群全时段的无界检索。跨聊天成功访问最近 100 条记录可从 `/aurabot/api/history/accesses` 或诊断导出查看，不保存查询正文或聊天全文副本。

先在主人私聊和一个明确选择的测试群逐项开启。保留现有凭证与数据，不要以复制运行中 SQLite 文件的方式自行实现恢复。

| 顺序 | 实机操作 | 应观察到的结果 / 需要记录 |

| 1 | 重载插件，查看模块与诊断；进行普通私聊、群 @、引用和语音回复 | 模块启动正常；旧会话不残留重复工具；语音不带自动引用；记录版本/模型/网关版本 |

| 3 | 主人与群友同批发言，然后主人单独提出一个测试管理请求 | 混合批次拒绝；独立请求正常走原权限。不要用真实删除或踢人作为首个验证动作 |

| 8 | 一张竖图/一张参考编辑，浏览作品库并复用，等待下一轮视觉反馈 | 服务收到支持的尺寸；参考图身份正确；只有当前人格看到已完成作品；记录 job_id |
| 9 | 先验证普通 TTS，再开启已有 RVC 音色；切人格/取消，检查失败回退 | 没有旧音色迟到发送；回退可辨认；记录转换耗时、错误和选定音色，不上传整个模型 |
| 10 | B 站文本浏览、按分 P/时间抽样、截图库；先只读验证登录恢复/@ 解析 | 截图记录实际/请求时间、分 P、方法；大段且无预览时明确失败；记录 BV/CID/秒数 |
| 11 | 需要时再显式要求一次测试弹幕或评论 | 实际主人请求、开关、额度和目标齐全才发送；结果 unknown 时先人工核对，不能重发试探 |
| 12 | 普通/目的主动搭话预览与 `/speak`；随后静默、撤目标或换人格 | 手动/定时一致；不越冷却、额度、静默；待发旧事件失效；记录 eventId |
| 13 | 连续 20 轮不同问题，启用学习与检索；切页、搜索导航、润色后选择采用 | 每轮动态资料更新而不累加到系统运行时上下文；草稿不丢，润色不自动发布 |
| 14 | 在受控测试任务中验证危险确认和 DSH 审批通知 | 关闭/卸载/超时后旧确认无效；QQ 只通知，宿主审批仍在 DSH 完成 |

出现问题时，提供发生时间与时区、聊天类型、功能开关、脱敏复现输入、请求 ID / job_id / eventId、预期与实际，以及「诊断 → 导出」和相邻日志。未知回执请同时保留 QQ/B 站实际界面是否出现该内容；不要为了补日志再次发送。不要提供 Cookie、Token、API Key 或完整未经检查的私人聊天库。

## 当前验证与明确限制

删除 O8 后重新执行 `npm test`：**1,506 项，1,502 通过，0 失败，4 跳过**。跳过的是 100k 事实性能用例、两个需真实 DSH 原生契约环境的用例，以及当前 Windows 账号无法创建文件符号链接的用例。`git diff --check` 通过；`npm pack --dry-run --json` 检查到 189 个分发文件，保留功能和两份新增文档均包含，已删除模块及 `.refactor` 未包含。测试数量减少 12 项，对应已删除模块的专用测试。

本次原始输出保存于被 Git 忽略的 `.refactor/test-after-o8-removal.log`，此前完整实现验证保留在 `.refactor/test-full-final.log`。面板使用隔离 Chrome、模拟 API 和本地 React 做过实际渲染/交互检查；部分视频/图像测试使用本机已安装的 FFmpeg 处理合成媒体。这些测试不是对真实 QQ/B 站回执或真实模型质量的证明。

- QQ、DSH 审批真实事件形状、网关文件下载参数和缓存 ID 仍需目标环境验证；没有声称已经跑过真实外部写入。
- B 站看画面需要视觉模型、FFmpeg 和可达的预览/CDN。预览时间可能是最近采样点，界面明确标注；回退每段最多 20 MiB、总共 40 MiB，没有可用预览且分段过大会失败。
- RVC 使用已配置转换器或已安装 Applio/模型。取消会及时返回；不配合取消的外部转换器结束前仍占用并发槽，临时目录在其结束后清理，不会放行第二个转换抢占资源。
- 大图缩图策略、动画降级限制和瞬时资源回收见 [图片附件说明](IMAGE-ATTACHMENTS.md)。缩图成功不等于模型已经理解图片。
- `.refactor` 只存审计、测试、浏览器预览临时数据，不纳入分发包。可选清理曾被自动审批拒绝，临时浏览器目录和参考文件仍留在那里。
