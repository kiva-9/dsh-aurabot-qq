# 模型图片附件的准备与回收

入站图片仍以原始资产和发生记录为准。提交给模型前会重新核验资产内容；有发生记录的图片还会核验账号、聊天和消息是否已撤回，异步处理后再检查一次。原图无损保留，最近媒体、历史引用和生图参考仍指向原资产。

预处理限制原图字节、解码像素、输出边长与字节、并发及超时。超过附件限制的静态图片由本机 ffmpeg 生成临时缩图，失败时明确标为图片不可用。需要缩小的动画不会静默退化为单帧；已有动画分析另按原有多帧采样流程处理。小图片经过容器结构校验，但此检查不等于完整解码每个像素。

临时缩图的字节只在本轮附件处理期间驻留内存，不写入共享资产库；处理结束后可由运行时回收，避免误删其他素材。`image_derivative_manifest` 为每个原资产至多保留一行最近缩图的 SHA-256、尺寸、MIME、用途和 `transient` 状态，记录血缘而不存缩图字节。它不是可重新读取的图片资产，也不记录模型是否成功看见图片。

未安装 ffmpeg 时，符合现有附件大小与尺寸限制的图片仍可直接使用；需要转码的图片会按不可用处理。网关返回本地缓存、动画和不同模型的真实接受情况仍需在目标 Windows / QQ / 模型环境验收。
